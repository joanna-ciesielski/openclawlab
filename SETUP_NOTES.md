## Documentation consulted (before any install command)

- https://docs.openclaw.ai/install/docker — canonical Docker guide
- https://raw.githubusercontent.com/openclaw/openclaw/main/docs/install/docker.md — same doc at source, cross-checked

Key facts taken from the official docs, not memory:

- Official path: run `./scripts/docker/setup.sh` from the repo root.
- Pre-built image: `export OPENCLAW_IMAGE="ghcr.io/openclaw/openclaw:latest"` (docs: avoid unofficial mirrors).
- Secrets: interactive onboarding prompts for provider keys; headless mode reads them from the Compose `.env` file. Gateway token is generated by setup and written to `.env`.
- Default bind mounts (host → container):
  - `~/.openclaw` → `/home/node/.openclaw` (config `openclaw.json`, auth profiles, workspace)
  - `~/.config/openclaw` → `/home/node/.config/openclaw` (auth-profile encryption key)
  - Overridable via `OPENCLAW_CONFIG_DIR` / `OPENCLAW_WORKSPACE_DIR` / `OPENCLAW_AUTH_PROFILE_SECRET_DIR`.
- Port: 18789 (gateway UI/API), health at `/healthz`.
- Container runs as non-root `node` (uid 1000), tini as PID 1, base `node:24-bookworm-slim`, drops NET_RAW/NET_ADMIN, no-new-privileges.
- RAM warning: 2 GB minimum for local builds (exit 137 on small hosts) → another reason to prefer the pre-built image.
